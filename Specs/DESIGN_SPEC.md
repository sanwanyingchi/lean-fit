# Lean Fit 原生视觉实现 Spec

版本：1.0  
基准画布：iPhone 15 Pro，393 × 852pt  
实现：SwiftUI 原生组件、SF Symbols、Swift Charts

## 1. 视觉源优先级

1. 用户后续明确确认的视觉决定。
2. 已确认的珊瑚色进展首页、动作选择方案 1、自定义动作 Sheet。
3. `lean-fit-prototype.html` 的页面结构、信息层级和交互状态。
4. `Lean-Fit-视觉与开发说明.md` 的通用可访问性与尺寸约束。

当前 HTML 原型使用绿色主色和头像入口，与后续确认冲突。生产端采用：珊瑚色作为品牌/主操作色，绿色仅作为“真实进步/完成”语义色；首页右上角使用档案图标，不显示头像圆点。

## 2. 语义 Token

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| background | `#F7F4F1` | `#12100F` | 页面暖白底 |
| surface | `#FFFFFF` | `#201D1B` | 卡片、Sheet |
| surfaceMuted | `#F1EEEB` | `#2B2724` | 输入、次级按钮 |
| textPrimary | `#171412` | `#F6F2EF` | 主文字 |
| textSecondary | `#77716D` | `#AAA29D` | 次级文字 |
| separator | 黑 8% | 白 10% | 分隔线 |
| brandCoral | `#FF4B2B` | `#FF664A` | 主 CTA、选中态、中心 + |
| brandCoralSoft | `#FFF0EB` | `#3A211C` | 柔和选中态 |
| progressGreen | `#2D8A4A` | `#42A861` | 真实突破、完成 |
| plum | `#6E405B` | `#B98AA7` | 极少量辅助强调 |
| destructive | systemRed | systemRed | 删除/错误 |

禁止把珊瑚色用于错误；错误必须使用 systemRed。普通正文优先用系统语义色，Token 通过动态 UIColor 提供深色适配。

## 3. 字体与数字

- 只使用系统字体 SF Pro。
- 页面标题：`.largeTitle.bold()`。
- Sheet 标题：`.title2.bold()`。
- 区块标题：`.title3.weight(.semibold)`。
- 正文：`.body`；次级：`.subheadline` / `.caption`。
- 重量、次数、趋势值使用 `.monospacedDigit()`。
- 不固定绝对字号，支持 Dynamic Type；紧凑控件可使用 `minimumScaleFactor(0.85)`，不可截断核心数值。

## 4. 间距与形状

- 页面左右边距 20pt；紧凑列表可用 16pt。
- 网格：4/8pt；常用 8、12、16、20、24、32。
- 卡片圆角 20pt；输入 14pt；主按钮 16pt；Sheet 使用系统圆角。
- 主按钮高度 56pt；列表行最小 60pt；所有点击区至少 44 × 44pt。
- 阴影只用于悬浮操作坞和中心 +，卡片主要依靠背景分组，不做卡套卡。

## 5. Root 与 Tab Bar

```text
┌─────────────────────────────┐
│ 内容区                       │
│                             │
├──────────────┬──────────────┤
│    进展      │      记录     │
│       ┌──────＋──────┐       │
└───────┴──────────────┴───────┘
```

- 进展为默认页；记录为时间轴。
- 中心 + 是 56pt 珊瑚色圆形按钮，上浮约 14pt，白色 `plus` SF Symbol。
- Tab Bar 使用原生 material，进展/记录选中图标使用珊瑚色。
- + 不拥有选中态，点击弹动作 Sheet；关闭后保留原 Tab。

## 6. 进展首页

- 顶部左侧“进展”，右侧保持 44pt 档案按钮；SF Symbol `person.text.rectangle` 使用 17pt light 和次级文字色，避免与页面标题、主操作争夺视觉重量。
- 趋势首卡：指标切换、最近值、周期变化、Swift Charts 迷你线图、时间范围、更新入口。
- 周训练：一周 7 列，完成日实心珊瑚；今天描边珊瑚；达成目标后可切换为进步绿确认态。
- 近期训练：最多两条，信息顺序为部位 → 动作摘要 → 日期/组数 → 突破标签。
- 无数据时保留布局骨架，用明确 CTA 指向中心 + 或更新身体数据。

## 7. 动作选择 Sheet

- 初始 medium，可上拉 large。
- 标题“选择本次动作”，右上圆形关闭按钮。
- 搜索框、最近/胸/背/腿/肩 chips、统一列表。
- 行左侧 32pt 圆形选择状态，主文字动作名，右侧上次表现和 chevron。
- 列表尾部使用低权重文本：`找不到动作？  ＋ 新建自定义动作`，不做卡片。
- 底部 material 操作坞：左侧“已选 N/4”，右侧珊瑚色“开始训练”。

## 8. 新建自定义动作 Sheet

- 标题“新建自定义动作”，右上关闭。
- 15 秒内完成：动作名称、主要部位为必填；负重方式默认普通负重；器械可选。
- 完整字段还包括别名、默认次数范围、默认加重档位，放在“更多设置” DisclosureGroup 内，兼顾 PRD 完整性和首屏简洁。
- 保存按钮位于底部拇指区；校验失败就地显示；成功后关闭本 Sheet，回到仍打开的动作 Sheet 并自动选中。

## 9. 训练页

- 顶部 Navigation Bar：“动作 / 训练中 / 结束”。
- 5pt 进度条、动作 1/4、动作名、已完成组数 pill。
- “上次表现”和“本次目标”并排，目标用珊瑚柔和底，突破语义才使用绿色。
- 组列表：组号、重量按钮、次数按钮、圆形完成按钮；数值用等宽数字。
- 底部固定“完成当前动作”和“查看其他动作”。
- 数值编辑器使用底部 Sheet，大数字、加减、档位、同步后续组。

## 10. 完成反馈

- 保存成功后进入 1–2 秒反馈层。
- 主反馈以具体事实为标题/大数字；没有突破时不得出现“变强”。
- 使用 SF Symbol、圆形颜色扩散、少量 Canvas 粒子和触感。
- 减弱动态效果开启时只做 150–250ms 淡入和颜色变化。
- 任意时刻可点“完成”跳过，不影响已保存数据。

## 11. 记录、档案与趋势

- 记录按月粘性标题和垂直时间轴；卡片不嵌套。
- 记录页右上角使用 17pt light 的 `calendar.badge.plus`，保留 44×44pt 点击区；点击后以 medium Sheet 拉起“训练打卡”。
- 打卡 Sheet 使用单张表单卡承载日期、训练部位和备注；标题栏不得与首行重叠。内容可滚动，底部 56pt“完成打卡”固定在安全区内，小屏和键盘出现时仍可到达。
- 详情逐动作显示组表、上次对比、突破和打卡状态。
- 档案不显示头像；顶部用“个人档案”标题和数据本地说明。
- 趋势不同单位永不叠加；力量必须先选择动作。
- 图表空/单点/多点各有独立状态。

通用 `Card` 必须先把 Builder 内容收敛为单一垂直容器，再统一应用内边距、圆角与背景；不得直接给多子视图 Builder 施加卡片修饰，避免每个子视图被拆成独立卡片。

## 12. 可访问性

- 图标按钮均提供 `accessibilityLabel`。
- 组记录行合并读法，例如“第 2 组，60 千克，8 次，未完成”。
- 图表提供摘要，不要求 VoiceOver 逐像素读取曲线。
- 不只依靠颜色表达完成/突破，必须配文字或 symbol。
- 支持 Reduce Motion、Differentiate Without Color、深色、高对比和 Dynamic Type。

## 13. 视觉验收

- iPhone 15 Pro 393×852pt 和小屏 iPhone SE 均无横向溢出。
- Sheet 的主 CTA 在键盘弹出时仍可到达。
- 首页、动作 Sheet、自定义动作 Sheet 与确认视觉稿的间距误差目标 ≤ 4pt。
- 浅色/深色截图均检查文字对比、截断、圆角、Safe Area 和 Tab Bar。
